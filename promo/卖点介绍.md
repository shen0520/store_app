> **一句话定位**：不用记价签，一扫就知道——专为小卖部、便利店、杂货店打造的离线扫码查价工具

## 二、四大核心功能模块

### 1️⃣ 录入新商品

> 扫描商品条码 → 填写名称、售价、进价 → 拍照上传 → 保存完成

- 支持 EAN-13、EAN-8、UPC-A、UPC-E、CODE-128、CODE-39、ITF 等全部常见条码
- 条码重复自动提示，防止误录
- 图片自动压缩（4MB→200KB），千款商品不卡顿

### 2️⃣ 快速扫码查价

> 对准条码一扫 → 超大字体显示售价 → 语音自动播报

- 售价字号 **56px 超大显示**，老远就能看清
- 语音开关自由控制，顾客多时播报，安静时静音
- 未录入商品一键跳转补录
- 连续扫描模式：扫完一个自动继续，盘点效率翻倍

### 3️⃣ 商品管理列表

> 全部商品一览 → 搜索/编辑/删除 → 上拉加载更多

- 分页加载，千条商品流畅滑动
- 搜索框 300ms 防抖，打字不卡顿
- 卡片式展示：图片、名称、品牌、售价、进价一目了然

### 4️⃣ 数据导入/导出

> 导出备份文件 → 微信/QQ发送 → 另一台手机导入合并

- **JSON 格式**：结构完整，含图片信息，程序友好（推荐）
- **CSV 格式**：Excel 直接打开，方便算账
- 三种冲突策略：跳过重复 / 覆盖本地 / 智能合并（保留最新修改）
- 一键清空数据，带二次确认防误触

## 六、使用流程示例

### 场景：新开小卖部，录入商品

```
1. 打开 App → 点击「录入新商品」
2. 对准商品条码扫描 → 自动识别条码数字
3. 填写商品名称（如「可口可乐 330ml」）
4. 填写本店售价：3.50 元
5. 填写进货价：2.50 元（仅自己可见）
6. 从相册选择商品照片 → 自动压缩保存
7. 点击「保存商品」→ 弹出保存成功
8. 重复以上步骤，录入全部商品
```

### 场景：顾客问价

```
1. 打开 App → 点击「快速扫码查价」
2. 对准商品条码 → 自动扫描
3. 屏幕显示：商品名称 + 超大字体售价 ¥3.50
4. 语音播报：「可口可乐 330ml，售价3.5元」
5. 告诉顾客价格，完成
```

### 场景：给店员同步价格

```
1. 店主手机 → 点击「数据导入/导出」
2. 点击「导出为 JSON」→ 保存到 Download 目录
3. 点击「分享文件」→ 选择微信 → 发送给店员
4. 店员手机收到文件 → 保存到本地
5. 店员打开 App → 数据导入/导出 → 导入数据
6. 选择刚才保存的 JSON 文件 → 选择「跳过重复」或「覆盖」
7. 导入完成，店员手机拥有和店主一样的价格表
```

## 七、常见问题（FAQ）

**Q：换手机了数据还在吗？**
> 不在。数据存在旧手机本地，换手机前请先在旧手机「导出 JSON」，新手机安装后「导入数据」。

**Q：需要联网吗？**
> 不需要。扫码、查价、录入全部离线完成。只有在首次下载安装时需要网络。

**Q：支持 iPhone 吗？**
> 当前版本仅支持 Android。iOS 版本可后续开发。

**Q：数据会丢失吗？**
> 正常不会。但卸载 App 或清除数据会丢失。建议定期导出 JSON 备份，发送到微信收藏或邮箱保存。

**Q：扫码识别不了怎么办？**
> 确保条码清晰、光线充足、对准扫描框。支持的条码类型包括商品常见的 EAN-13（13位数字条码）。
